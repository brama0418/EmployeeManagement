About Employee Management System

Employee Management System is a simple web application used to manage employee information in an organization.

This system helps to store, view, search, update and delete employee details easily.

Features

  • Add new employee details
  • View employee information
  • Search employees by name
  • Edit employee details
  • Delete employee details
  • User Registration and Login
